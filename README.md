# 🚨 Detecção de Fraudes em Transações

Projeto desenvolvido para identificar transações fraudulentas utilizando técnicas de **Machine Learning**, contemplando desde a análise exploratória dos dados até a avaliação e comparação de diferentes modelos de classificação.


---

# 📊 Dataset

O conjunto de dados utilizado neste projeto é o **Credit Card Fraud Detection Dataset**.

> ⚠️ O arquivo **creditcard.csv** não está incluído neste repositório devido ao limite de tamanho do GitHub.

Para reproduzir o projeto, faça o download do dataset e salve-o em:

```text
data/raw/creditcard.csv
```

# 🎯 Objetivo

Desenvolver modelos de Machine Learning capazes de identificar transações fraudulentas, avaliando diferentes abordagens e comparando seu desempenho por meio das métricas de classificação.
